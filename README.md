# Градоначальникъ

Браузерная стратегия-управление о том, откуда взялись деньги. Ты правишь людьми от племени у реки до первого банка: пять эпох, около 40 ходов, 30–40 минут игры.

**Играть:** https://baddrummer14.github.io/gradonachalnik/ (без регистрации и установки)

## Что делает игрок
- Решает события: кнопкой из вариантов советников или **своим решением словами**. ИИ разбирает решение и считает последствия.
- Раскладывает людей по делам: мужчины, женщины, старики и дети годятся для разного.
- Издаёт законы своими словами. ИИ учитывает их во всех следующих событиях.
- Слушает советников-карьеристов: они помнят обиды, сами просят тайной аудиенции, их можно прогнать.
- Строит постройки, выполняет цель эпохи. В финале летописец пишет историю правления и даёт прозвище.

## Как устроен ИИ
- Цифры считает код, ИИ (Gemini) только толкует решения, сочиняет аудиенции, события из истории игрока, новых советников и летопись. Ответ ИИ ограничен рамками, поэтому игра не ломается.
- Пока ИИ думает, советники перебрасываются репликами, а аудиенции и события готовятся заранее, пока игрок читает текущий ход.
- Ключ API не лежит в браузере: запросы идут через прокси на Cloudflare Workers (`proxy/worker.js`, ключ в секрете). Если ИИ недоступен, игра продолжает работать на заготовках.
